My Projects

This page showcases my personal portfolio website, which I developed while learning Systems Development. I used HTML and CSS to create and design my website.

HTML - Website Structure

I used HTML to create the structure of my website. I learned how to add headings, paragraphs, images, lists, navigation links and contact forms.

CSS - Website Styling

I used CSS to improve the appearance of my website. I learned how to add colours, backgrounds, fonts, spacing, navigation bar styles and project cards.

Website Navigation

I created four connected pages: Home, About, Projects and Contact. I used HTML links to allow visitors to move between the pages.

Responsive Web Design

I learned how to use CSS media queries and flexible layouts to make my website adjust to different screen sizes, including computers and mobile phones.

Contact Form

I used HTML form elements such as input, select, label and textarea to create a contact form where visitors can enter their information and write messages.

Skills and Knowledge Gained

Through this project, I improved my understanding of HTML, CSS, website structure, web design, navigation and problem-solving.

Languages and Technologies Used

  • HTML - Building the website structure.
  • CSS - Styling and designing the website.
  • JavaScript - A programming language I am learning for website interactivity.
  • Visual Studio Code - Writing and editing code.
  • Live Server - Previewing my website in a browser.

What I Learned

Developing this personal portfolio website has helped me gain practical experience in web development. I have learned how to structure web pages, style websites, connect different pages and create forms.
